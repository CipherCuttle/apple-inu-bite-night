# Style + Maze Run V0

- Combat multiplier is now driven by an authoritative style meter rather than raw kill-chain tiers.
- Rank ladder: D STRAY -> C HUNGRY -> B FERAL -> A RABID -> S UNLEASHED -> SS HELLHOUND.
- Repeating the same attack yields sharply less style; changing attacks gets a variety bonus.
- Dismemberment and physics kills award named style events, rendered as pooled scrolling combat text.
- Taking damage cuts style and can drop rank. Style decays after a grace window.
- Style affects score only; it does not make normal attacks faster. Last Bite remains the only temporary speed rescue.
- The arena becomes a clean authored maze with deterministic flow-field navigation, 20 active zombies, a BONEFIRE start, and a sealed exit.
- The exit unlocks after 18 kills. Reaching it ends the run as a maze clear. Death returns the player to the Bonefire on restart.
- This is a Soulslike/maze-runner skeleton, not yet a full corpse-recovery/shortcut/metaprogression system.
